# Privacy / 隐私声明

- `storage` is used solely to remember your Gemini Notebook group layout, folder membership, and whether a source is enabled so the panel retains your configuration. (`storage` 仅保存你的 Gemini Notebook 分组布局、文件夹归属和来源的启用状态。)
- `tabs` is used only to find, focus, or open the Gemini Notebook tab that already contains the source manager; no content from the page is read, stored outside the browser, or shared with external services. (`tabs` 只是为查找、聚焦或打开 Gemini Notebook 标签页，未读取页面内容，也不向外部发送数据。)
- The extension never sends Gemini Notebook content or derived metadata to external servers. All state syncing happens inside the browser and uses Chrome's local storage APIs. (扩展从不向外部服务器发送 Gemini Notebook 内容或推导出的元数据。所有状态同步均在浏览器内完成，使用 Chrome 的本地 storage API。)
- No analytics, crash reporting, or telemetry is embedded by this release. The packaged code ships inside the extension zip, and the UI references no remote resources at all — the symbol font used for the injected panel controls is bundled locally (`src/assets/fonts/google-symbols.woff2`) and loaded from the extension's own `chrome-extension://` origin, so no request is made to Google or any CDN. (此版本没有嵌入分析、崩溃上报或遥测。扩展代码全部随 ZIP 打包分发；UI 不引用任何远程资源——注入面板控件所用的图标字体是随扩展打包的本地文件（`src/assets/fonts/google-symbols.woff2`），从扩展自身的 `chrome-extension://` 源加载，不向 Google 或任何 CDN 发起请求。)
- The settings panel can open the Chrome Web Store feedback page. Diagnostics are not sent automatically; they leave your browser only if you choose to copy and submit them to Chrome Web Store yourself. (设置面板可以打开 Chrome Web Store 反馈页面。诊断信息不会自动发送；只有当你主动复制并提交到 Chrome Web Store 时，才会离开浏览器。)
