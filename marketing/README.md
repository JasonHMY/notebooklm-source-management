# Promotion Workspace

This folder keeps product promotion material for GeminiNotebook-Source-Management. It is not part of the Chrome extension runtime and is not included in the release zip.

## Folder Map

- `account-matrix.md`: account ownership, platform positioning, login/security notes, and publish status.
- `content-calendar.md`: weekly publishing plan and post backlog.
- `platform-playbooks.md`: platform-specific positioning, content format, and review checklist.
- `assets/README.md`: place to track screenshots, covers, demos, and exported design files.

## Installed Local Skills

The following user-level skills were installed for social promotion work:

- `xiaohongshu`: Xiaohongshu content and workflow assistance. Review before use because the installer reported high security risk.
- `twitter-x-automation`: X/Twitter automation assistance.
- `social-publisher`: general social publishing workflow assistance.
- `social-media-image-sizes`: image size reference for social platforms.

Use these skills for drafting and planning first. Keep account login, posting, and bulk interactions under manual review unless the platform API and account rules are clear.

## Product Positioning Seed

- Product: GeminiNotebook-Source-Management.
- Audience: Gemini Notebook users who manage many sources, folders, tags, or repeated research projects.
- Core promise: make large Gemini Notebook source lists easier to organize, recover, and maintain.
- Trust angle: local Chrome extension, no backend, no external database, and privacy-focused source management.
